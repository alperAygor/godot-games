# F5 — Reklam servisleri portu (mock'lu) · rapor

Dal: `orch/na-f5` · Durum: tamamlandı, `tools/verify.sh` yeşil. Ayrıntılı tasarım ve API: `docs/MONETIZATION.md`.

## Mimari
Şablondan (`studio-kit/template-mobile`) taşınan: `AdsProvider` arayüzü, `NoAdsProvider`, `AdmobAdsProvider` + `AdmobBridge` + `PoingAdmobBridge`
(yalnız Android yerel tekil nesneleri varsa etkin; eklenti yok), AdManager fikri. Bu projeye göre YENİ/uyarlanan: tipli `AdPlacement.Id`
(REVIVE, DOUBLE_CORES, REROLL, DAILY_BONUS, INTERSTITIAL), `AdConfig` (ads.json doğrulama), `AdEnvironment` (+ `SettingsAdEnvironment`: F4 bayrakları),
saf koşu/süre tabanlı `AdPacing`, belirleyici ve ayarlanabilir `MockAdsProvider` (başarı/erken kapatma/doluluk yok/zaman aşımı + bekletilebilir onay),
onay kapısı (consent çözülmeden istek yok), isteğe bağlı gizlilik-seçenekleri yeteneği, `Ads` cephesi. Çevrimiçi kapısı ve seviye tabanlı pacing alınmadı.
Autoload: `project.godot` yalnız `AdManager="*res://scripts/autoload/AdManager.gd"` satırı.

## Pacing kuralları (AdPacing.evaluate, sıra bu) ve testleri (`test_ad_pacing.gd`, `test_ad_manager.gd`)
remove-ads → disabled → moment ≠ run_end → ödüllü izlendi → runs ≤ 3 → ölüm < 2 → saat geri → süre < 180. Ödüllü yerleşimler pacing'e tabi değil.
Testler: ilk 3 koşu (0–3) yok / 4 ve 50 var; 179 yok / 180 / 181 var / 0 sn yok / hiç gösterilmediyse sınır yok; saat geri (+10 sn, +400 gün) yok;
ölüm 0,1 yok / 2,5 var; ödüllü izlendi yok (veri kapatırsa var); remove-ads her koşulda yok, ödüllü etkilenmez; yanlış anlar; veriyle yönetilme; bozuk veri.
Yönetici düzeyi: 2. ölümde gösterir, ardından 180 sn dolmadan yok (179 yok/180 var), revive ve çift çekirdek sonrası yok, başarısız gösterim süreyi başlatmaz, `then` tam bir kez.
